# Personal Rules

- Respond in Japanese unless the user requests otherwise.
- Use Conventional Commits format (`<type>(<scope>): <subject>`) for all git commits. Allowed types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `chore`, `ci`, `build`, `revert`.
- Prefer existing custom tools (`zemo`, `gcp`, `fm`, `y`) over inventing new ones for the same purpose.
- Don't run `git push` without explicit user approval, even if commit was approved earlier in the session.
